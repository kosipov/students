# Посредник для расписания (Yandex Cloud Function)

`index.py` — функция, которая ходит на campus.syktsu.ru вместо сервера сайта. Нужна, если кампус не отвечает на запросы с адреса сервера.

Как создать — в [DEPLOY.md](../../DEPLOY.md), раздел «Если кампус не отвечает серверу».

Кратко:
- среда выполнения `python3.12`, точка входа `index.handler`, таймаут 30 с, память 128 МБ, функция публичная;
- переменные функции: `RELAY_SECRET` (обязательно), `CAMPUS_URL` (по умолчанию страница расписания преподавателя);
- переменные сайта в Dokploy: `CAMPUS_RELAY_URL` (ссылка для вызова) и `CAMPUS_RELAY_SECRET` (то же значение, что `RELAY_SECRET`).

Функция не является открытым прокси: она делает POST только по адресу из `CAMPUS_URL` и только для тех, кто знает секрет.
